# V0.3 · 森林会回应你

## 交付范围
在 V0.2 上增加蘑菇、溪流涟漪、角色环境反应和首次进入流程。保持 React + TypeScript + GSAP、两场景、图片角色与 CSS 视差，无新运行时依赖。此版是待人工体验确认的开发版本，不代表 V1.0 发布。

- 蘑菇使用独立透明 WebP；图像、光晕与按钮共用一个随视差移动的定位容器。轻触亮起后约两秒恢复，650ms 冷却。
- 水纹位于背景溪流所在的底部区域，深度与背景一致；最多三组，结束或切场景清除。音效最短间隔 300ms。
- 灯串由熄灭切到点亮时角色抬头；夜景淡入结束后挥手；蘑菇/溪流触发闭眼倾听。
- 默认动作锁阻止用户连续点击叠加；自动反应最多保存最新一个。用户操作可打断自动反应，不能打断自己的当前动作。切场景、后台与卸载清理动画和队列。
- 首次进入后短暂提示点击角色，实际手动互动后记住已发现；提示本次最多出现一次。保存静音偏好，存储拒绝时仅退化为本次会话状态。
- 核心背景与 idle 角色完成下载、解码后开放入口；核心失败显示重试。重试重建画面节点，避免旧失败图片残留。音频由入口点击解锁，不阻塞准备。
- 可选角色帧失败时回到 idle 图继续动画；蘑菇图失败时隐藏并禁用热点。夜景按需加载，失败保留当前场景并支持再次点击。
- 所有场景热点共用 useTap：超过 10px 的拖动不会产生点击；指针捕获保证离开小热点后仍能识别拖动。键盘点击可用。

## 结构与边界
| 模块 | 职责 |
| --- | --- |
| scenes/types.ts、forest.ts、nightForest.ts | 图层、音景、角色光色、互动定位（含手机）、语义反应映射 |
| scenes/registry.ts | 场景目录、动态加载入口与下一场景选择 |
| hooks/useSceneTransition.ts | 准备新场景 → 淡出/推进 → 更新配置 → 淡入；过期资源取消 |
| lib/resources.ts、hooks/useEntryResources.ts | 核心/可选资源划分、12 秒超时、解码、取消、重试 |
| hooks/useSceneInteractions.ts | 互动事件 → 声音及语义角色请求；组件不互相控制 |
| character/types.ts、hooks/useCharacterAnimation.ts | 统一 idle/wave/jump/lookUp/listen 语义，blink 独立；来源优先级、单槽队列、动作完成与取消 |
| components/Character | 当前图片渲染器，帧加载回退；位置和光色来自 SceneConfig |
| components/Mushrooms、Water、LightString | 局部视觉反馈与 useTap 点击判定 |
| lib/preferences.ts、store/experienceStore.ts | 仅持久化 music/greeted 两个布尔偏好 |
| audio/ForestAudio.ts | 总开关管理全部声部；新增蘑菇/水纹合成短音 |

将来替换 GLB 时，保留场景位置、语义请求与用户优先级；将具体图片/GSAP播放部分抽为渲染适配器。当前完成/取消为 hook 内部生命周期，尚未引入公开的 GLB 适配 API，避免提前增加引擎依赖。
