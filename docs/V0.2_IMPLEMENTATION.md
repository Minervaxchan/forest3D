# forest3D V0.2 — 角色与声音优化

本版在 V0.1 的 Scene System 上迭代，不引入 3D 引擎、GLB、后端或额外运行时依赖。

## 体验改动

### 角色与场景融合

SceneConfig 新增 characterLighting（filter、contactOpacity、rim），分别配置日光和月光的角色亮度、饱和度、边缘光与接触阴影。角色底部以透明蒙版叠加微弱环境反射色，不影响透明区域。

原先整体悬浮式 idle 改为脚底为轴的轻微呼吸。阴影拆成柔和地面投影和更集中的脚下接触阴影；跳跃过程中，投影随离地变小、变淡，落地回弹时恢复。角色位移和视差仍在不同容器上执行。

### 动作与输入

- 新增透明闭眼与抬手招呼帧，均以 V0.1 角色为参考生成；保留蓝眼睛、绒毛、头顶轮廓与白鞋。
- blink 使用真实闭眼图替换 CSS 黄色眼睑覆盖。
- wave 使用抬手姿态配合轻微身体摆动。仍是精灵帧动画，没有骨骼和独立手指动作。
- 三帧同为 640×640；同时加载，切换仅修改 opacity。额外帧未加载或加载失败时继续使用 idle。
- 动作同步 ref 锁防止重复点击；过场禁用角色时取消动作并恢复状态。
- 拖动角色时记录位移，避免将超过 10px 的拖动误识别为点击；键盘点击仍可触发。
- reduced-motion 保留姿态反馈，取消明显跳跃与摆动。

源图在 src/assets/character/friend-blink-source.png / friend-wave-source.png，运行时图在 public/assets/character。npm run assets:build 可重建，生成提示记录在 ASSET_PROMPTS.md。

### 声音

音频逻辑从 hook 分离至 src/audio/ForestAudio.ts。useAudio 只处理点击解锁、生命周期、静音与后台恢复。

音频链路：

- 音乐节点 → 场景 music 增益 → 场景 bus → master → 压缩器 → 输出
- 环境节点 → 场景 ambience 增益 → 场景 bus
- 交互短音 → master

- 音乐增加四组和弦、留白旋律、柔和拨弦音色与少量混响。
- 环境增加两条低成本噪声循环，经过滤波和缓慢调制，分别模拟溪流与风吹树叶。
- 日间有稀疏鸟鸣；夜间使用更轻的短促虫鸣，以及不同根音/节奏的音乐。
- 抬手、起跳、落地、灯串点击有短促音效，受同一个静音开关控制。
- 场景声音用独立 bus 交叉淡化 1.2 秒，不再直接停止旧曲。
- 旧场景立即停止排程，淡出后回收音源、计时器与音频节点。
- 150ms 排程器仅在前台且 AudioContext running 时补充少量未来音符，后台不积累声音。
- 音乐与环境音仍支持外部 src。加载失败回退合成声景，过期请求取消；卸载时释放会话。
- 混响缓冲区匹配实际设备采样率；噪声缓冲区使用 22050Hz 以降低内存占用。

**所有新增声音仍为原创程序合成，不是实地环境录音或正式授权音乐。** 当前重点是验证声景层次、混音和交互，之后可替换为高质量循环音频。

## 验证

- npm run build / npm run lint。
- 生产版本：1440×900 桌面与 390×844 手机模拟。
- 入口、鼠标/触摸视差、灯串、场景切换、夜景懒加载与失败后重试。
- wave/jump 两分支、动作锁、实际闭眼/抬手图片、跳跃阴影反馈。
- 通过音频分析节点确认有非零输出，静音后音乐和环境声归零。
- 场景过渡后环境循环数量回到 2，确认旧声音释放。
- 后台 AudioContext 暂停/恢复、无横向溢出、无控制台错误、reduced-motion。
- 截图保存在 docs/screenshots/v0.2；报告在 docs/verification-v0.2.json。

浏览器测试不能替代真实手机的陀螺仪授权、低端设备帧率和耳机听感验收。

## 运行

npm run dev 使用 5186；npm run preview 使用 4186，均启用 strictPort，避免误用其他项目的预览。
npm run test:e2e 默认访问开发端口 5186；设置 TEST_BASE_URL=http://localhost:4186 验证生产预览。

## 后续

优先真机试听并调节环境声/音乐比例，再增加手臂的独立连续挥动；保留目前的语义动作与 SceneConfig 边界，将来替换 GLB Character 无需重写场景/音频系统。
