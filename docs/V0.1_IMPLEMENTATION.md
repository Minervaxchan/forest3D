# forest3D V0.1 实现说明

## 目标与技术选择

验证森林氛围、角色反馈、声音和场景切换。原仓库仅 README / .gitignore，因此新增 Vite + React + TypeScript + GSAP，不引入 Three.js、GLB、后端或数据库。App 仅挂载 Experience。

## 工程结构

- src/components/Experience：场景组合、入口、过场、第二场景加载与失败回退。
- src/components/Character：透明 WebP 渲染器，角色位置和比例由场景配置输入。
- src/components/AudioController / SceneSwitcher：两个主要控制按钮。
- src/components/LightString / Fireflies：灯串与粒子。
- src/hooks/useParallax：鼠标、触摸、可选陀螺仪；rAF 平滑更新 CSS 变量，不对 pointermove setState。
- src/hooks/useCharacterAnimation：idle / blink / wave / jump 与同步 ref 锁、动画清理。
- src/hooks/useAudio：AudioContext、合成 BGM、外部 BGM / 环境音接口、音量渐变与后台挂起。
- src/store/experienceStore：useSyncExternalStore 驱动的轻量共享状态，无额外状态库。
- src/scenes/forest.ts / nightForest.ts / types.ts：场景配置。
- src/assets：可重新压缩的源素材；public/assets：实际按 URL 加载的 WebP 和音频目录。
- scripts/optimize-assets.mjs：重新生成运行时 WebP。
- scripts/verify.mjs：真实浏览器交互验收与截图。

## 场景与层级

SceneConfig 包含 id、name、subtitle、background、layers、bgm、ambient、characterPosition、characterScale、lightMode、effects。

| 层 | 内容 | 视差强度 |
| --- | --- | --- |
| background | 参考图衍生的大树、溪流、远景整体底图 | 12 |
| midground | 独立透明雾光 + 可交互灯串 | 26 / 27 |
| character | 透明角色 + 脚下阴影 | 20 |
| foreground | 独立透明前景枝叶和蕨类 | 44 |
| effects | 小型萤火粒子、暗角 | 屏幕空间 |

**当前大树仍烘焙在底图中，没有把原图中的每棵树抠成独立层。** 真实深度来自不同速度的底图、雾光、灯串、角色与前景。后续可增加树干/树冠中景图层，不必改输入系统。

视差在容器上更新 --px / --py，每层使用 --depth。内层 GSAP 镜头、角色动作和外层视差分开，避免 transform 相互覆盖。叶片仅 ±0.25° 摆动。

夜景配置 dynamic import；夜景图片在首次点击切换时预加载。加载完成后旧场景淡出并轻微推进/模糊，在完全不可见时换配置，新场景淡入；锁定切换按钮至过场完成。失败保留旧场景、解除锁并展示重试提示。共享叶片和雾光复用浏览器缓存。

## 角色

采用用户三视图中黄色绒毛、蓝色大眼睛、白鞋、三瓣头顶的原创角色，使用参考衍生透明 WebP。不是护目镜/背带裤造型。

- idle：低幅度呼吸/摆动。
- blink：随机间隔，定位于眼部的眼睑覆盖层，约 140ms。
- wave：整角色摇摆招呼；V0.1 没有单独手臂骨骼或逐帧挥手。
- jump：蓄力压缩、上跳、落地回弹。
- ref 锁在点击同步设置，防止连续点击叠加；GSAP 完成时回 idle。
- 卸载清除动作时间线与眨眼计时器。

## 输入与可访问性

桌面鼠标；移动端拖动；设备支持且授权时陀螺仪增强。拒绝、不支持、非安全上下文均继续支持触摸。拖动后暂时优先采用触摸输入，避免传感器抢视角。按钮提供中文 aria-label、aria-pressed 与键盘焦点。prefers-reduced-motion 关闭环境循环和视差，过场仅短淡入淡出，角色用轻量缩放反馈。

## 音频

入口点击内创建/恢复 AudioContext。音乐开关对 GainNode 进行渐变；切后台先淡出，再 suspend，返回后 resume 并尊重静音选择。后台不继续添加合成音符。拒绝播放时显示重试信息。

V0.1 BGM 是原创正弦和弦/旋律占位声景，日夜使用不同根音与节奏，无商用音频素材。填写 bgm.src 后加载并循环音频；加载失败回退合成音乐。ambient: {src, volume} 为环境音预留接口，当前没有环境录音。资源通过 AudioBufferSourceNode 接入同一总音量节点。场景切换时重启对应曲目，暂未实现独立曲目交叉淡化。

## 性能与限制

运行时主要素材约 0.96 MB，其中夜景约 0.30 MB 延迟加载；角色约 58 KB。生产 JS gzip 约 104 KB。粒子日间 18 / 手机 10，夜间 26 / 手机 14，纯 transform / opacity。图片压缩为 WebP，透明通道保留。短时过场使用 blur，无持续高成本 shader。页内无外部字体/图片网络依赖。

390×844 / 1440×900 已用 Edge 浏览器模拟验证。实际 iOS Safari、真实陀螺仪授权流程、扬声器听感和低端安卓帧率仍需真机验证；自动化确认的是 AudioContext 状态及音量节点，不代表人工听音验收。

## 未来替换 GLB 的边界

1. 保留 SceneConfig、场景加载、过场、音频和 useParallax。
2. 给 Character 增加 renderer: sprite | glb、asset 与 clips 数据，仅替换角色内部实现。
3. 场景百分比位置由 Character 宿主继续掌控；GLB 只占角色局部画布，避免把整个页面改成 3D。
4. 将当前 idle / blink / wave / jump 转为语义动作接口，GLB renderer 映射动画片段；锁与结束回调行为保持一致。
5. 后续若升级全场景，再新增 renderer，不改变 scene id / 音频配置 / UI 入口。

第一版不安装任何 3D 依赖，以上是接口演进方案，不是已实现的 GLB 功能。

## 验证

执行 npm run build、npm run lint；浏览器检查覆盖入口、音频解锁/静音、角色状态锁与动作结束、灯串、触摸/鼠标视差、夜景延迟加载、日夜往返、后台挂起与恢复、控制台、无横向溢出与 reduced-motion。结果见 verification.json，截图见 screenshots/。
